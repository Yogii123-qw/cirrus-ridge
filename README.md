Cirrus Ridge: fly a small red plane through rings over a green valley, then bring it home to the runway. Three missions share one valley: a ring course that rewards clean lines, a low canyon time trial, and a landing challenge judged on touchdown softness and centreline accuracy. The flight model has real stall behaviour, fuel that runs out, gear and flaps, and a chase camera that rolls with the plane. The cockpit view carries a full HUD with altitude, speed and heading tapes, an artificial horizon, throttle and fuel gauges, and a next-ring pointer. Every sound is synthesised WebAudio. It plays with keyboard and mouse on desktop, with no network request at all. Best scores are kept in the browser's local storage on the player's own machine.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
